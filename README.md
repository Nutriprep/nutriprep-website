# nutriprep.app

Webseite der iPhone-App NutriPrep. Reines HTML/CSS, ohne Build-Schritt, gehostet mit GitHub Pages.

| Datei | Inhalt |
|---|---|
| `index.html` | Startseite |
| `datenschutz.html` · `impressum.html` · `support.html` | Pflichtseiten |
| `assets/style.css` | Aussehen (Farben ganz oben) |
| `assets/site.js` | Sprache, Hell/Dunkel, Animationen |
| `assets/screens/` | Platz für echte App-Screenshots |
| `CNAME` | Domain für GitHub Pages |

Texte ändern: Jeder Text steht zweimal nebeneinander, `<span class="de">…</span>` und `<span class="en">…</span>`. Beide anpassen.

Keine Cookies, kein Tracking, keine externen Schriften.
